Faites sonner votre téléphone à plein volume en lui envoyant un SMS. Il sonne à plein volume, même en silencieux. Aucune connexion internet n’est nécessaire : il fonctionne même avec un faible signal mobile.

Les localisateurs en ligne ne font sonner qu’un téléphone connecté à internet et vous obligent à vous connecter à un compte sur un autre appareil, à établir une connexion avec votre téléphone... SMS Ring a juste besoin du réseau mobile. Ni internet, ni compte, ni connexion à un compte.

► Plein volume, même en silencieux ou vibreur
► Vibration en option et mode vibration seule
► Choisissez votre phrase secrète pour le faire sonner
► Autorisez les messages de n’importe quel numéro ou seulement des numéros de votre choix
► Toi seul peux l’arrêter : ton code ou ton empreinte est demandé

► Privé par conception, pas par promesse
SMS Ring n’a pas l’autorisation internet. Le système bloque lui-même toute connexion : vos données ne peuvent physiquement pas quitter votre téléphone. Ni compte, ni pub, ni statistiques, ni serveur.

CONFIGURATION (IMPORTANT !) : Apple ne permet pas aux apps de lire les messages. SMS Ring vous guide pour créer en 1 minute une automatisation Raccourcis indispensable pour que l’app puisse lire le message reçu. De plus, tout message censé faire sonner le téléphone doit contenir le mot « sonne ». SMS Ring l’ajoute quand vous copiez ou partagez le message.

► Open source : Vous pouvez vérifier vous-même
Tout le code est public pour que vous puissiez l’examiner sur GitHub
